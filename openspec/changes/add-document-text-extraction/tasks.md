## 4. Extractor

- [ ] 4.1 Add the content-kind detection (design D2) as a pure function over the leading bytes: PDF, PNG, JPEG, TIFF (both byte orders), anything else. Cover it with unit tests: each signature, a ZIP signature, content shorter than a signature, and empty content. Verify they pass.
- [ ] 4.2 Add the per-page rule (design D3) as a pure function over a page's text: at least 20 letters or digits means "use the text layer". Cover it with unit tests: 0, 19 and 20 letters, digits counted, whitespace and punctuation not counted. Verify they pass.
- [ ] 4.3 Add the `TextExtraction` options class bound from the `TextExtraction` configuration section (design D6): languages (`deu+eng`), the two program names, the per-run time limit (120 seconds). Verify `OfficeRkyv.Api` builds.
- [ ] 4.4 Add the program runner: start a process from a file name and an argument list without a shell, capture standard output, enforce the time limit, kill the process tree on timeout and on cancellation, and report "could not start", the exit code or "timed out" as a result and not as an exception. Cover it with unit tests using `sh` and `sleep` from the dev shell: output captured, non-zero exit code reported, a program that does not exist reported as not started, a run over the limit killed. Verify they pass.
- [ ] 4.5 Add the two interfaces of design D6 (render one PDF page to an image file; read an image file to text) and their implementations on top of the runner, with the argument lists recorded in task 1.3. A failed run logs one Warning with the content hash, the page number and the exit code through a `[LoggerMessage]` method. Cover the argument lists and the mapping of a failed, timed-out and not-started run to "unread" with unit tests through a fake runner, including that the Warning carries no program output. Verify they pass.
- [ ] 4.6 Add the extractor that ties 4.1 to 4.5 together: detect the kind; for a PDF open it with PdfPig, apply the rule per page, render and read the pages that need OCR, and treat a PDF that cannot be opened or is encrypted as unreadable; for an image read it directly; return the outcome, the pages and the counts. Remove the rendered image of each page from `tmp/` when done. Verify `OfficeRkyv.Api` builds; behaviour is covered in group 6.
- [ ] 4.7 Add the hosted service of design D7 that checks both programs and the configured languages once at start and logs one Information or one Warning through `[LoggerMessage]` methods, never failing the start. Cover each combination (both found, one missing, a language missing) with unit tests through a fake runner and a capturing logger. Verify they pass.
